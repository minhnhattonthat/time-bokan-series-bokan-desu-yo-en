# Glossary - Time Bokan Series: Bokan desu yo

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated. Name order: Western (given name first).
- Romanisation source: official English names where they exist, else an earlier fan patch, else Hepburn without macrons.
- Credits: English.
- Register / flavour: slapstick parody of the Time Bokan anime; keep the villains' catchphrases punchy. Sound effects: subtitle spoken grunts and cries as written words ("Gaaah!", "Arooo!"); no bracketed effect captions.
- Spelling: American (Color, honor).
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening.
- Graphics text: all translated. The ボカンですよ logo stays Japanese, as no official English logo exists.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ -> ..., ！？ -> !?
- Stage cards end on a character catchphrase (だコロン, だペッチャ): keep it as a verbal tic rather than dropping it.

## Decisions from earlier batches
- Dialogue tics, by speaker: Dokurobey ", y'hear"; Tonzra ", I tell ya"; Boyacky "little ol' me" for ボクちゃん, ", yes indeed" for はい, "Doku-chan" for ドクちゃん. Full table in `docs/style-reference.md`.
- 悪玉 = villain, evil, bad guys; 善玉 = good guys, heroes, by what the line needs. Credit rows say "etc." for ・他.
